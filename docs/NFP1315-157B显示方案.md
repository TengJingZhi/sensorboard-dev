# NFP1315-157B 比赛信息显示方案

## 目标
在 ESP32-S3 从板（sensorboard-dev）上接入 NFP1315-157B（1.57 寸 OLED/SSD1315 类，I2C）显示屏，实时显示：

- 比赛状态：等待 START / 比赛中（含已运行秒数）
- 7 路振动开关状态
- 4 路激光开关累积状态
- 状态变化时自动刷新，并带 500ms 周期兜底刷新

## 硬件连接

| 显示屏 | ESP32-S3 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 16 |
| SCL | GPIO 17 |

> 引脚在 `include/display.h` 中可通过 `DISPLAY_SDA_PIN` / `DISPLAY_SCL_PIN` 调整。
> 当前从板已占用 GPIO 4~15、41、42，因此 I2C 选在 16/17。

## 软件结构

- `include/display.h`：显示模块接口与引脚定义
- `src/display.cpp`：U8g2 初始化与渲染
- `src/main.cpp`：显示快照、变化检测、周期刷新集成

## 显示布局（128x64）

```text
Status: RUN 12s      <- 或 Status: WAIT
Vib: 0001000         <- 7 位，1 表示当前锁存振动
Lsr: 1010            <- 4 位，1 表示激光已触发
Auto refresh
```

## 刷新策略

- 变化触发：`flowStarted`、`vibrationActive`、任一 `laserAcc` 变化时立即刷新。
- 周期兜底：无变化时每 500ms 刷新一次，防止偶发漏更新。
- 未收到 START 前也会刷新本地传感器状态用于显示，但不会向主板发送数据。

## 比赛状态

当前版本按本地推断：

- 上电 / 未收到 START：`WAIT`
- 收到 START：`RUN` 并显示运行秒数

后续如需“结束/暂停/分数”等状态，可扩展主板 UART 指令（例如 `UART_MSG_MATCH_STATUS`），在 `receiveFromMain()` 中解析并同步到显示。

## 验证项

- [ ] 上电显示 `Status: WAIT`
- [ ] 收到 START 后显示 `Status: RUN 0s` 并持续计时
- [ ] 触发振动时对应位变 1，屏蔽结束后变 0
- [ ] 遮挡激光后对应位变 1 并保持
- [ ] 长时间运行无明显闪烁
